HOW TO VIEW
1. Extract this folder if it was downloaded as a ZIP.
2. Open index.html in Chrome, Edge, or Firefox.
3. Keep index.html and style.css in the same folder.

FILES
- index.html: semantic HTML5 page and content
- style.css: all layout, visual styling, and responsive media queries
- PROJECT_DESCRIPTION.txt: short description for internship submission
- screenshots/: desktop and mobile preview images

NOTES
- This project follows the HTML & CSS internship brief: no JavaScript, React, Bootstrap, backend, or database.
- The optional Google Fonts import requires an internet connection; fallback fonts are included.
- External links point to the portfolio owner's supplied project/profile destinations.
