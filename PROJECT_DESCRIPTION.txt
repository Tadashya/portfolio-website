Tadashya Priyadarshini — Personal Portfolio Website

This personal portfolio introduces me as a web developer and B.Tech student specialising in Artificial Intelligence and Machine Learning. It includes Home, About, Skills, Projects, Education, and Contact sections to present my background, technical toolkit, selected projects, and professional links. The website is built with semantic HTML5 and a separate CSS3 stylesheet, using CSS Grid, Flexbox, hover states, accessible link labels, and responsive media queries for mobile and desktop screens. The visual design uses a consistent green, cream, and lime palette with custom CSS project previews. External project links open in a new tab. The site is a static HTML/CSS project and does not use JavaScript, a backend, or a database.
